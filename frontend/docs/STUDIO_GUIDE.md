# PolyGen 3D Studio User Manual & Interface Guide
*Author: Kailash-18 (Frontend Lead)*

## Overview
PolyGen provides a real-time WebGL studio for generating, inspecting, and customizing 3D game-ready assets.

## Viewport Controls
- **Orbit & Pan**: Click and drag with primary mouse button to rotate; right-click and drag to pan.
- **Zoom**: Scroll wheel or pinch gesture to zoom between 1.0m and 15.0m distance boundaries.
- **Turntable**: Toggle the turntable rotation icon in the top toolbar to begin smooth 360-degree turntable review.

## Shading Modes
1. **Textured (PBR)**: Full physically-based rendering displaying 1024x1024 Albedo, Normal, and Roughness maps.
2. **Clay**: Matte studio clay shader with custom surface tint options (Slate, Chalk, Terracotta, Charcoal).
3. **Wireframe**: Topology viewer with customizable edge colors (Cyan, Violet, Amber, White).

## Camera Presets
Access the Viewport & Material Studio drawer to switch between CAD views:
- **Perspective**: Standard 3D spatial viewport
- **Front (1)**: Orthogonal front elevation
- **Side (3)**: Orthogonal side elevation
- **Top (7)**: Plan view
- **Isometric**: Fixed 45-degree axonometric projection
- **Reset View**: Instantly re-centers the model in camera frame

## Snapshot Capture
Click the Camera icon in the floating studio bar to capture an uncompressed high-resolution PNG render directly from the WebGL framebuffer.
